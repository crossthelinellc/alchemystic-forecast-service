# Alchemystic forecast service

This is the corresponding source for Mystic Rebels’ universal Alchemystic Astrology forecast
service. It calculates directional Aspect Arcs with Swiss Ephemeris and exposes the versioned JSON
feed consumed by the Mystic Rebels Shopify theme.

The implementation, tests, container definition, calculation contract, and license notice live in
[`integrations/alchemystic-forecast`](integrations/alchemystic-forecast/README.md).
